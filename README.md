# Skills Desk

ChatGPT skills are closer to a folder than to a feature: instructions, examples and scripts the assistant picks up on its own when a task calls for them.

**Read the full page:** https://chatgpt-skills.github.io/

If you repeat the same multi-step task in the same way every week, and you are on a workspace plan that includes them, this is the right mechanism: package the instructions once and let the assistant apply them automatically instead of pasting a prompt template. If you are on a personal plan, the eligibility list is the first thing to check, because availability is tied to Business, Enterprise, Healthcare and Edu accounts and to workspace settings. The caveat is trust: uploaded skills carry instructions, files and code, and the automated scan is explicitly not a substitute for reading what you installed. For workflows that end in a rendered video or image rather than a document, Kyncept covers that part in the browser.
